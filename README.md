## CA-PINN-for-RDE

Contains the code to solve and calibrate reaction-diffusion equations with Constraint-Augmented Physics-Informed Neural Networks.


## Documentation

Start by reading the documentation. You can open the notebook `CPINNs_RD.ipynb` and modify it as you wish to simulate the solution of the 1D Fisher-KPP equation with travelling waves as observations.


## Libraries

To run the code, this library is needed
- pytorch

## Test

For the 1D Fisher-KPP, you can run `python fisher_kpp_1d_pinnLphys.py`


For the 2D Fisher-KPP, you can run `python fisher_kpp_2d_NoVarPro.py`


For the 1D Allen-Cahn, you can run `python allen_cahn_1d_NoLphys.py`
